# 写真の指示（鋼製模型橋の再試験 2026）

公開先：https://ymmtlab-utsukuba-matlab.github.io/field-photo-guide-2026/

鋼製模型橋の再試験（1日目 10/28、2日目 10/29、3日目 10/30、4日目 10/31、5日目 11/01、6日目 11/02）で、手順ごとに「この写真を撮ってください」と、何をどこからどの向きで撮るかを 3D で示すアプリです。実験の参加者がスマートフォンで開きます。

- 写真は受け取らず、保存しません。端末に残すのは「撮った」の印と押した時刻だけです（ブラウザの localStorage）。
- 計測データ・写真・個人の情報は入っていません。
- `install_records/` は、どの台をどの位置に付けるかの割り当て表から作った、前処理用の設置の記録（CSV）です。

使い方はアプリの「使い方」にあります。3D の表示に three.js 0.160.0（MIT ライセンス、jsDelivr から読み込み）を使います。橋・試験車・センサの 3D は研究室で作った表示用の模型で、寸法の正本ではありません。
